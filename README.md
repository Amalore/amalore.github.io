# Marie Amalore Nambi — academic website

This repository contains the source for [amalore.github.io](https://amalore.github.io), built with Jekyll and the Minimal Mistakes remote theme.

## Edit the site

- Profile and site settings: `_config.yml`
- Main navigation: `_data/navigation.yml`
- Homepage: `index.md`
- Other pages: `_pages/`
- Custom styles: `assets/css/main.scss`
- Profile image: `images/profile.jpg`

## Preview locally

Install Ruby and Bundler, then run:

```bash
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000` in a browser. Pushing changes to the `main` branch publishes the site through GitHub Pages.
